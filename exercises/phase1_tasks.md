# 第一阶段练习

不要直接增加更复杂的模型。先保证每个结论都能通过实验验证。

## 必做

1. 手推二连杆末端位置和雅可比，并与代码逐项对应。
2. 用有限差分计算数值雅可比，验证 100 个随机关节位形，记录最大误差。
3. 随机生成 20 个可达目标，从至少 3 个不同初始位形求解，统计收敛率。
4. 分别使用阻尼 `0.001、0.01、0.05、0.2`，比较奇异位形附近的误差和关节更新幅度。
5. 为逆运动学加入关节上下限，证明求解结果不会越界。
6. 将直线轨迹替换成五次多项式时间缩放，并画出位置、速度和加速度。

## 进阶

1. 给目标加入末端朝向，将雅可比扩展为 `x、y、theta` 三行。
2. 加入零空间目标，让冗余三连杆在到达目标的同时远离关节限位。
3. 使用 DH 或 POE 方法实现一个三维 6 轴机械臂的正运动学。
4. 为每个新增功能补自动测试，禁止只凭动画判断正确性。

## 实验报告必须回答

- 奇异位形处，雅可比的秩和条件数发生了什么？
- 阻尼增大为什么会提高稳定性，却降低最终精度或收敛速度？
- 同一个末端目标为什么可能有多组关节解？
- 为什么逐点 IK 不能替代带碰撞约束的运动规划？
